# 全国大学生嵌入式芯片与系统设计竞赛 - 工程标准交付包

## 一、 项目简介
本项目基于 FPGA 开发板（Xilinx Artix-7 xc7a200t），实现了一套完整的 **深紫外/可见光空间光通信 (VLC) 系统**。系统支持通过 PC 端串口（9600 bps）输入数据，经过 FPGA 组帧与 PWM 调制后，通过光发射模块发送；接收端进行光电转换、PWM 解调及协议解析，最终通过串口回传至 PC。在串口空闲期间，系统会自动循环发送“2017至2026 FPGA创新设计竞赛国赛十周年”文本。

## 二、 目录结构导航
- `02_board/`: 包含全部 RTL 源码 (`rtl/`) 与 XDC 物理约束 (`constraints/`)。
- `03_build/`: 包含一键构建工程脚本 (`build_project.tcl`) 与 QoR 资源/时序校验脚本 (`check_qor.tcl`)。
- `04_data/`: 测试激励数据及黄金参考结果，包含 20m 光路实测的示波器波形、串口输出截图与实物搭建图。
- `05_skill/`: 踩坑与排雷指南 (`FPGA_Pitfalls.md`)，记录了开发过程中的多次死锁、多驱动与固化失败的解决经验。
