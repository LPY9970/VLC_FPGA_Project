# 2026 嵌入式芯片与系统设计竞赛（AMD 赛题）—— 日盲深紫外单工光通信系统

## 1. 项目简介
本作品设计并验证了一套日盲深紫外单工光通信系统。
发射端采用 275nm 深紫外 LED 作为光源，搭配紫外增透石英透镜压缩光束发散角。
接收端选用高灵敏度光电倍增管（PMT），前置窄带深紫外滤光片，有效抑制背景杂散光干扰。
基带处理以 ALINX AX7202 (Xilinx Artix-7) FPGA 为核心，采用 UART 通信协议与**自定义 PWM（脉宽调制）**方案，完成数据的无损传输。
系统通信距离达 20 米，物理层通信速率 1 Mbps，可覆盖文本传输、指令传输等业务。

## 2. 硬件与开发环境
- **FPGA 核心板**：ALINX AX7202 (XC7A200T-2FBG484I)
- **开发软件**：Xilinx Vivado 2018.3 及以上版本
- **发射端硬件**：275nm DUV LED、OPA2677 驱动、MOSFET 驱动电路
- **接收端硬件**：PMT 探测器、TIA 跨阻放大器、高速比较器

## 3. 目录结构说明
- `02_board/`：FPGA 核心 RTL 源码 (`rtl/`) 与 XDC 物理引脚约束 (`constraints/`)。
- `03_build/`：包含一键构建脚本 `build_project.tcl` 与 QoR 资源/时序自动化校验脚本 `check_qor.tcl`。
- `04_data/`：测试激励数据及黄金参考结果，包含 20m 光路实测的示波器波形、串口输出截图。
- `05_skill/`：踩坑与排雷指南 (`FPGA_Pitfalls.md`)，记录开发中“死锁”、“多驱动”等问题的解决经验。
- `README.md`：项目简介与复现步骤。

## 4. 复现步骤 (Quick Start)
1. **一键构建工程**：打开 Vivado，在 Tcl Console 中切换至 `03_build/` 目录，执行 `source build_project.tcl`。脚本会自动创建工程、生成 IP 产物、跑完综合与实现并直接输出 Bitstream。
2. **质量校验 (可选)**：生成 Bit 后，执行 `source check_qor.tcl`。脚本会自动抓取 WNS 和 LUT 资源，与预设红线比对，确保时序无违例。
3. **确认顶层与引脚**：确认发射端顶层为 `tx_top.v`，接收端为 `rx_top.v`；检查 `constraints/top.xdc` 中的引脚是否与板卡一致。
4. **烧录与上板**：将生成的 `.bit` 文件通过 JTAG 烧录至两块 ALINX 板卡。
5. **系统联调**：两块板卡上电并对准光路。通过 PC 端串口助手（配置：**9600 波特率, 8-N-1**），即可观察到双工/单工的文字与指令传输。

## 5. 物理层通信参数 (技术验证)
- **通信速率**：1 Mbps (每 bit 周期固定为 1us)。
- **调制方式**：PWM 脉宽调制。
  - 逻辑 `1`：高脉冲宽度约 500ns (占空比 50%)。
  - 逻辑 `0`：高脉冲宽度约 240ns (占空比 24%)。
- **协议帧结构**：`A6 CE D5` (帧头) + 10 Bytes (有效载荷)。
- **空闲模式**：串口持续 50ms 无输入时，自动进入循环广播模式，发送预设中文文本。
